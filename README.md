# Text Log Studio v1.0

## 실행

Node.js 18 또는 20 권장.

```bash
npm install
npm start
```

`http://localhost:3000`에서 열립니다. 배포 빌드는 `npm run build`입니다.

## 기능

- TXT 붙여넣기/불러오기 → 화자/나레이션/장면 제목 자동 분석
- 블록 유형, 화자, 내용, 순서 직접 수정 및 추가/삭제/복제
- 캐릭터별 인장 이미지 및 색상, 장면 이미지와 배경 이미지 등록
- 다크/라이트 미리보기
- 브라우저 localStorage 자동 임시 저장
- JSON 프로젝트 백업/불러오기
- 이미지 포함 독립 HTML 내보내기 (스크롤 읽기 전용)

## 파싱 규칙 (v1.0)

- `화자: 대사`처럼 `화자:`로 시작하면 화자 블록
- 같은 문단에서 다음 `화자:`가 나오기 전까지 행동과 대사를 같은 화자 블록으로 유지
- 빈 줄로 구분된 문단이 따옴표로 시작하면 직전 화자의 후속 대사로 처리
- 그 외 별도 문단은 나레이션
- `###01. 입대.` 등은 장면 제목
- 문맥에 따라 모호한 부분은 블록 편집 화면에서 수동 교정

## 저장 주의

자동 저장은 브라우저의 localStorage에만 저장됩니다. 브라우저 데이터 삭제, 다른 PC 이동, 이미지 용량 초과에 대비해 JSON 백업을 자주 저장하세요. 이미지 파일은 파일당 최대 8MB, PNG/JPEG/GIF/WebP 지원. HTML과 JSON에 이미지가 Base64로 포함되므로 파일 크기가 증가할 수 있습니다.

원본 TXT는 편집 과정에서 자동 변경되지 않습니다. 재분석은 편집 블록을 새로 생성하므로 기존 수정을 덮어쓸 수 있습니다.
