# TEXT LOG STUDIO

**TXT 로그를 읽기 편한 HTML 로그로 변환하는 웹 편집기**

Text Log Studio는 텍스트로 작성된 대화 및 TRPG 세션 로그를 분석하고, 화자별 대사와 나레이션을 편집하여 HTML 파일로 내보낼 수 있는 웹 도구입니다.

별도의 프로그램 설치나 회원가입 없이 브라우저에서 사용할 수 있습니다.

### [TEXT LOG STUDIO 바로가기](https://lumia-sh.github.io/TextLogStudio/)

## 주요 기능

- **TXT 로그 분석** — TXT 파일 불러오기 또는 직접 붙여넣기
- **두 가지 분석 모드** — 일반 모드와 확장 모드 지원
- **블록 편집** — 화자, 나레이션, 장면 제목, 이미지 블록 추가 및 수정
- **캐릭터 설정** — 화자별 인장 이미지 및 색상 지정
- **이미지 등록** — 장면 이미지와 배경 이미지 추가
- **실시간 미리보기** — 편집 결과를 즉시 확인
- **테마 설정** — 편집기와 로그 미리보기의 다크/라이트 모드 개별 설정
- **자동 저장** — 브라우저 IndexedDB에 작업 내용 저장
- **프로젝트 백업** — JSON 파일로 저장하고 다시 불러오기
- **HTML 내보내기** — 이미지가 포함된 독립 HTML 파일 생성

## 사용 방법

### 1. 원문 가져오기

웹사이트에서 **01 · 원문 가져오기**를 선택합니다.

TXT 파일을 불러오거나 텍스트를 직접 입력한 뒤, 원문 형식에 맞는 분석 모드를 선택합니다.

### 2. 분석 모드 선택

| 구분 | 일반 모드 | 확장 모드 |
|---|---|---|
| 화자 인식 | `이름: 대사` | `이름: 대사` |
| 빈 줄 1개 | 화자 블록 종료 | 같은 화자 블록의 문단 구분 |
| 빈 줄 2개 | 화자 블록 종료 | 화자 블록 종료 |
| 장면 제목 | `# 장면 제목` | `# 장면 제목` |

**일반 모드**는 대사와 나레이션을 빈 줄 하나로 구분하는 TXT 로그에 적합합니다.

```text
캐릭터 A: "문을 열어보겠습니다."

문이 열리자 어두운 복도가 나타납니다.

캐릭터 B: "안쪽을 확인해 볼게요."
```

**확장 모드**는 화자의 대사와 행동 묘사를 하나의 블록으로 묶고 싶을 때 사용합니다.

```text
캐릭터 A: "문을 열어보겠습니다."

조심스럽게 문고리를 잡고 돌린다.


문이 열리자 어두운 복도가 나타납니다.

캐릭터 B: "안쪽을 확인해 볼게요."
```

분석 결과는 완벽하지 않을 수 있으며, 문맥에 따라 모호한 부분은 블록 편집 화면에서 직접 수정할 수 있습니다.

### 3. 블록 편집

**02 · 블록 편집**에서 분석된 로그를 수정합니다.

- 화자 / 나레이션 / 장면 제목 / 이미지 유형 변경
- 블록 내용과 화자 이름 수정
- 블록 순서 이동
- 블록 추가, 복제, 삭제

원본 TXT와 편집된 블록은 별도로 유지됩니다.

단, **원문을 다시 분석하면 기존 블록의 수정 내용이 교체될 수 있으므로** 주의해 주세요.

### 4. 캐릭터 및 디자인 설정

**03 · 캐릭터 / 이미지**에서 화자별 색상과 인장 이미지를 등록할 수 있습니다.

**04 · 디자인**에서 로그 테마와 배경 이미지를 설정할 수 있습니다.

편집기 화면의 다크/라이트 모드와 내보낼 로그의 테마는 별도로 관리됩니다.

지원 이미지 형식은 PNG, JPEG, GIF, WebP이며 파일당 최대 8MB입니다.

### 5. HTML 내보내기

상단의 **HTML 내보내기** 버튼을 누르면 독립적인 HTML 파일이 생성됩니다.

캐릭터 인장, 장면 이미지, 배경 이미지는 HTML 파일 내부에 포함되므로 별도의 이미지 폴더 없이 열 수 있습니다.

내보낸 HTML은 읽기용 결과물입니다. 다시 편집하려면 JSON 프로젝트 백업을 이용해 주세요.

## 프로젝트 저장 및 백업

Text Log Studio는 작업 내용을 **현재 브라우저의 IndexedDB에 자동 저장**합니다.

별도의 서버 계정이나 클라우드 동기화 기능은 제공하지 않습니다.

**주의사항**

- 브라우저의 사이트 데이터를 삭제하면 저장된 프로젝트가 사라질 수 있습니다.
- 다른 브라우저나 PC에서는 기존 작업이 자동으로 나타나지 않습니다.
- 중요한 작업은 **JSON 백업** 기능을 이용해 별도로 보관해 주세요.
- JSON 및 HTML 파일에 이미지 데이터가 포함되므로 이미지가 많으면 파일 크기가 커질 수 있습니다.

## 로컬 개발 환경

React 18과 Create React App 기반으로 제작되었습니다.

Node.js 18 또는 20 환경을 권장합니다.

### 설치

```bash
npm install
```

### 개발 서버 실행

```bash
npm start
```

브라우저에서 `http://localhost:3000`으로 접속합니다.

### 프로덕션 빌드

```bash
npm run build
```

### GitHub Pages 배포

```bash
npm run deploy
```

배포 설정은 `package.json`의 `homepage` 및 `gh-pages` 스크립트를 사용합니다.
